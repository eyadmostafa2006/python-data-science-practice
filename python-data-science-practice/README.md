Bigger projects live in their own repositories:

* [Heart Failure Univariate Analysis](https://github.com/%5Byour-username%5D/heart-failure-univariate-analysis)
* [Egypt House Prices Analysis](https://github.com/%5Byour-username%5D/egypt-house-prices-analysis)

## Contents

|Folder|Notebook|Topics|
|-|-|-|
|`01-python-basics`|`strings-basics.ipynb`|Variables, types, string methods|
|`01-python-basics`|`practice-20-problems.ipynb`|Conditions, loops, lists, functions|
|`01-python-basics`|`functions-and-loops.ipynb`|Input handling, calculator, factorial, string and list utilities|
|`02-numpy`|`numpy-basics.ipynb`|Arrays, indexing and slicing (1D/2D/3D), math and summary functions|
|`03-data-cleaning`|`car-sales-data-cleaning.ipynb`|Duplicates, missing values, type conversion, EDA on a dirty dataset (`car\_sales\_data\_dirty.csv` included)|

## How to run

```bash
pip install -r requirements.txt
jupyter notebook
```

Each notebook's dataset is included in its folder.
